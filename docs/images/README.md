# Screenshots

This directory contains screenshots for the Arciv README.md file.

## Screenshots needed:

- `screenshot-main.png` - Main interface showing URL input and link list
- `screenshot-ai.png` - AI classification showing summaries and tags
- `screenshot-feeds.png` - Feed management interface
- `screenshot-telegram.png` - Telegram bot interaction

## How to add screenshots:

1. Take screenshots of the Arciv interface
2. Save as PNG files in this directory
3. Ensure they're properly sized (recommended 1200x800)
4. Compress images for web (keep under 200KB each)
5. Update README.md with actual screenshot references

For MVP release, these can be placeholder images or actual screenshots.
